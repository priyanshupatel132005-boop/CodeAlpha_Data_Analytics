# CodeAlpha Data Analytics Internship Tasks

This repository contains the projects completed during my Data Analytics Internship at CodeAlpha.

## 📁 Repository Structure
* **Task 1: Web Scraping**
  * `web_scraper.py`: Python script utilizing BeautifulSoup to extract and structure raw web data into a CSV format.
* **Task 2: Data Cleaning & Preprocessing**
  * `data_analysis.py`: Python script leveraging Pandas to clean missing records, normalize text fields, and convert data types.
  * `tableau_ready_dataset.csv`: Fully preprocessed, large-scale dataset structured specifically for advanced business intelligence modeling.

## 📊 Business Intelligence Visualizations
* The clean dataset from Task 2 was imported into **Tableau Public** to build an interactive, high-impact **Packed Bubbles Performance Dashboard** for visual analytics.# CodeAlpha_Data_Analytics
